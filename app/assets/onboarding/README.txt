ONBOARDING PICTURES
===================
slide-1.jpg, slide-2.jpg and slide-3.jpg are the three welcome slides shown the first time the app opens
(the same pictures for every store). To change one, replace the file with another picture of the same
name (.png, .jpg, .jpeg or .webp all work), about 1100 px wide. Landscape pictures (like the current
ones, 1100 x 600) are shown in full, without cropping, so any text inside them stays readable.
The slide-N.svg files are only a fallback for when a picture is missing.
